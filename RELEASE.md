# Version 0.2.0 - Templates

### Compatibility

* Supports Nextcloud 30 – 35 (tested with Nextcloud 35), PHP 8.3 or newer

### Features

* Templates for new entries: an empty entry offers "Use template", which inserts
  a Markdown skeleton into the editor. Entries written with a template are normal
  Markdown entries, so editing and the PDF/Markdown export work as before.
* First template: "Gefühle wahrnehmen (3 Fragen)" – what touched me emotionally today,
  what did I feel in my body, what would I have needed in that moment
* More templates can be added in `src/templates.js`
